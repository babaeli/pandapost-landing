## 🎭 Animation Timeline

### On Page Load
- Hero content: Fade in + slide up (0.8s)
- Hero visual: Fade in + slide up (0.8s, 0.2s delay)
- Floating cards: Start floating animation

### On Scroll
- Feature cards: Fade in when 10% visible
- Benefit cards: Fade in when 10% visible
- Solution cards: Fade in when 10% visible
- Workflow steps: Fade in when 10% visible

### On Hover
- All buttons: Lift up 2px + enhance shadow
- Feature cards: Lift up 8px + enhance shadow
- Workflow steps: Scale to 105%
- Social icons: Lift up 4px

### Continuous
- Floating cards: Up and down motion (3s cycles)
- Demo mascot: Gentle floating (3s cycle)
- Hero mascot: Subtle parallax on scroll

## 📐 Z-Index Layering

```
Layer 1000: Navigation (sticky)
Layer 100:  Floating cards
Layer 10:   Raised cards on hover
Layer 2:    Mascot images
Layer 1:    Section backgrounds
Layer 0:    Base content
```
